# AI 전환 2단계 체크리스트

## 범위
- [ ] 오더 등록 폼 전환이 포함된다.
- [ ] 오더 수정 폼 전환이 포함된다.
- [ ] 예약일시(연/월/일 + 시/분) 입력이 포함된다.
- [ ] 예약 기준(픽업/인도) 처리와 역산 표시가 포함된다.
- [ ] 주소/경유지/연락처 입력이 포함된다.
- [ ] 차종/차량번호 분리 입력이 포함된다.
- [ ] 요금 프리뷰 및 도선 관련 표시가 포함된다.
- [ ] 생성/수정 API 계약은 기존과 동일하게 유지한다.

## 계약 테스트
- [ ] POST /orders 요청 필드 계약 동일
  - [ ] reserved_date
  - [ ] reserved_time
  - [ ] pickup_reserved_date
  - [ ] pickup_reserved_time
  - [ ] vehicle_type
  - [ ] vehicle_number
  - [ ] memo_customer
  - [ ] fare_amount
- [ ] 폼 유효성 검증 동일
- [ ] 예약 기준 전환 시 저장값 동일
- [ ] 요금 프리뷰 API 결과 반영 동일
- [ ] 숨김 필드 동기화 누락 없음
- [ ] 주소 검색/지도/경로 계산 동작 동일
- [ ] 콘솔 에러 없음 확인

- [ ] 월말 경계 시나리오 확인
- [ ] 윤년/2월 경계 시나리오 확인
- [ ] 차종 미입력/입력 케이스 확인
- [ ] 요금 수정/저장/조회 왕복 확인
- [ ] 모바일/데스크톱 레이아웃 확인
- [ ] 실제 업무자 확인 승인
