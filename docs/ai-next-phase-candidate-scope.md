# Next 전환 1차 후보 범위 (현재 코드 기준)

이 문서는 현재 Express + EJS + vanilla JS 구조를 유지한 상태에서, Next.js/Vite 전환을 실제로 시작할 때 어떤 화면부터 옮겨야 하는지 우선순위를 정리한다.

## 결론
- 1차 전환 대상은 **읽기 전용 화면**이다.
- AI 챗봇/상담 실시간 플로우는 기능 결합도가 높아 1차 대상이 아니다.
- 오더 입력 폼은 2차로, 상담관리/실시간 플로우는 3차로 둔다.

## 1차 대상 화면
1. 대시보드
2. 오더 목록(조회 전용)
3. 문의 목록(조회 전용)
4. 상담 세션 목록(읽기 전용 리스트/카드)

## 1차 제외 화면
- 오더 등록/수정 폼
- AI 챗봇 입력/응답 화면
- 상담관리 실시간 메시지/배정/읽음 처리
- 세션 삭제/숨김/종료와 같은 상태 변경 흐름

## 1차 전환 이유
- 조회 화면은 API 계약 유지가 상대적으로 쉽다.
- 폼/실시간 플로우보다 롤백이 쉽다.
- 화면 단위 회귀 테스트를 먼저 만들기 좋다.
- Next/Vite의 데이터 패칭/라우팅 구조를 안정적으로 검증하기에 적합하다.

## 1차 전환 시 확인할 계약
- 인증/세션 리다이렉트
- 필터/검색/페이지네이션
- 권한별 노출(admin/branch_manager/client)
- 숫자/상태 배지/정렬 기준
- 모바일/데스크톱 레이아웃

## 1차 전환 후 넘어갈 조건
- 계약 테스트 통과
- 스테이징 실사용 검증
- 롤백 경로 확인
- 운영자가 읽기 전용 화면에 대해 기능 회귀 없음을 승인

## 이후 순서
- 2차: 오더 등록/수정 폼
- 3차: 상담관리/실시간 플로우
- 4차: AI 챗봇/접수 도우미(가장 마지막)
