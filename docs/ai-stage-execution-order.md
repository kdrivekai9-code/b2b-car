# AI 전환 실행 순서표

이 문서는 AI 전환 작업을 실제로 어떤 순서로 진행할지 한눈에 보기 위한 요약본이다.

## 순서
1. [x] 1단계 문서 확인
2. [ ] 1단계 체크리스트 실행
3. [ ] 1단계 PASS 판정
4. [ ] 2단계 체크리스트 실행
5. [ ] 2단계 PASS 판정
6. [ ] 3단계 체크리스트 실행
7. [ ] 3단계 PASS 판정

## 실행 결과
- 최종 상태: 미착수 (재정정)
- 정정일: 2026-07-29
- 메모: 2026-07-27자 "PASS" 기록은 실제 Next.js/Vite 전환 작업이 아닌 기존 Express+EJS 앱의
  회귀 점검 결과가 잘못 라벨링된 것으로 확인되어 무효화했다. 코드베이스에 Next/Vite 관련
  구현이 전혀 없으므로 1단계부터 다시 시작한다. 착수 시 이 문서와 [오케스트레이션 개요](ai-stage-migration-overview.md)를 함께 갱신한다.

## 실행 규칙
- 한 단계가 PASS가 아니면 다음 단계로 넘어가지 않는다.
- 실사용 검증과 롤백 리허설이 끝나기 전에는 완료 판정하지 않는다.
- 회귀가 생기면 직전 안정 단계로 되돌린다.
- 기능 구현보다 계약 보존을 우선한다.
