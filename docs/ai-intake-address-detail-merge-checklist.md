# AI 챗봇 주소 상세 병합 테스트 체크리스트

목적
- AI 챗봇에서 주소 확정 시 `주차장/입구/정문` 같은 부속어가 누락되지 않고 상세주소에 병합되는지 검증한다.
- 모호 주소 분기(1번/2번 선택)에서도 동일하게 동작하는지 검증한다.

사전 조건
- 화면: 오더 접수 > AI 챗봇
- 대상 필드: 출발지 주소, 도착지 주소, 각 상세주소
- 네트워크 정상 (주소 검색 API 응답 가능)

---

## 1) 기본 자동확정 케이스

### TC-01 도착지 `주차장` 병합
입력
- `수완한양수자인아파트 주차장`

기대 결과
- 도착지 주소가 지도 검색 결과의 메인 주소로 확정된다.
- 도착지 상세주소에 `주차장`이 자동 입력되거나 기존 값 뒤에 추가된다.
- 챗봇 확인 문구에 `주차장`이 포함되어 보인다.

체크 포인트
- 상세주소 중복 없음 (`주차장 주차장` 금지)
- 확인 문구와 폼 값이 일치

### TC-02 출발지 `입구` 병합
입력
- `광주역 입구`

기대 결과
- 출발지 상세주소에 `입구` 반영
- 챗봇 확인 문구에 `입구` 포함

### TC-03 부속어 없음
입력
- `광주역`

기대 결과
- 기존 동작 유지 (부속어 강제 추가 없음)
- 상세주소 자동 부속어 입력 없음

---

## 2) 모호 주소(1번/2번) 선택 분기

### TC-04 `주차장` 포함 + 후보 분기 + 1번 선택
입력 흐름
1. `OO아파트 주차장` 형태로 모호 분기 유도
2. 챗봇 질문: `1번/2번 중 어느 곳이 맞을까요?`
3. 사용자 응답: `1번`

기대 결과
- 선택한 후보 주소로 메인 주소 확정
- 상세주소에 `주차장` 병합
- 확인 문구에 병합된 표현 노출

### TC-05 동일 조건 + 2번 선택
입력 흐름
- TC-04와 동일, 응답만 `2번`

기대 결과
- 2번 후보 적용
- 상세주소에 `주차장` 병합 유지

### TC-06 후보 문구 직접 입력 선택
입력 흐름
- `1번/2번` 대신 후보 라벨의 일부 텍스트를 입력

기대 결과
- 해당 후보 선택 처리
- 상세주소 병합 정상

---

## 3) 중복/보존/회귀 케이스

### TC-07 기존 상세주소가 이미 있는 경우
사전 상태
- 도착지 상세주소에 `101동` 입력됨

입력
- `수완한양수자인아파트 주차장`

기대 결과
- 상세주소: `101동 주차장` 형태로 병합
- 기존 값 보존

### TC-08 같은 값 재입력 시 중복 방지
입력
- 같은 주소를 연속 2회 처리

기대 결과
- 상세주소에 같은 부속어가 중복 추가되지 않음

### TC-09 place_name 중복 접두어 방지
상황
- 확인 문구 조합 시 place_name이 상세주소에 이미 포함된 데이터

기대 결과
- 확인 문구에서 불필요한 중복 텍스트 없음

---

## 4) 부정 케이스

### TC-10 주소 검색 실패
입력
- 의미 없는 문자열

기대 결과
- "검색이 되지 않았습니다" 안내 노출
- 주소/상세주소 필드 비정상 값으로 오염되지 않음

### TC-11 너무 짧은 검색어
입력
- 1~2글자 수준

기대 결과
- 자동확정 미수행 또는 결과 없음 처리
- 에러 없이 다음 입력 가능

---

## 5) 최종 등록 데이터 확인

### TC-12 저장 payload 검증
절차
1. 도착지에 `... 주차장` 입력 후 자동확정
2. 오더 등록 실행
3. 서버로 전송된 값 확인

기대 결과
- `destination_address`: 메인 주소
- `destination_detail_address`: `주차장` 포함
- 최종 저장 주소 조합 시 `메인주소 + 상세주소` 형태로 반영

---

합격 기준
- 위 12개 케이스 모두 통과
- 확인 문구/폼 표시/저장 데이터 간 불일치 0건
- 상세주소 중복 삽입 0건
