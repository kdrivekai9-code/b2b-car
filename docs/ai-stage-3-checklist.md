# AI 전환 3단계 체크리스트

## 범위
- [ ] 상담관리 세션 리스트/카드 전환이 포함된다.
- [ ] 실시간 채팅/상담 플로우 전환이 포함된다.
- [ ] AI 인입 우측 패널 전환이 포함된다.
- [ ] 읽음 상태/배정/종료/삭제/재개 흐름이 포함된다.
- [ ] 세션 카드의 주문 접수 요약이 포함된다.
- [ ] 실시간 스트림(SSE/EventSource) 동작이 포함된다.
- [ ] 기존 상담 데이터 계약은 유지한다.

## 계약 테스트
- [ ] 세션 목록 조회 계약 동일
- [ ] 세션 상세 조회 계약 동일
- [ ] 메시지 전송 계약 동일
- [ ] 실시간 스트림 이벤트 형식 동일
- [ ] 읽음 상태 업데이트 계약 동일
- [ ] 세션 배정/해제 계약 동일
- [ ] 종료/삭제/재개 API 계약 동일
- [ ] AI 인입 파싱 결과 반영 계약 동일
- [ ] 카드 요약 표시값 누락 없음
- [ ] 콘솔 에러 없음 확인

## 스테이징 실사용 검증
- [ ] 신규 세션 생성 5건 이상
- [ ] 상담원 배정/해제 5건 이상
- [ ] 메시지 송수신 20회 이상
- [ ] 읽음 표시/미읽음 표시 확인
- [ ] 세션 종료 후 재개 확인
- [ ] 삭제 후 목록/상세 반영 확인
- [ ] AI 인입 결과에서 오더 접수 내용 반영 확인
- [ ] 카드 요약과 상세 화면 값 일치 확인
- [ ] 모바일/데스크톱 레이아웃 확인
- [ ] 실제 업무자 확인 승인

## 롤백 경로
- [ ] 상담관리 화면을 기존 서버 렌더/EJS로 즉시 복귀 가능
- [ ] 실시간 스트림 경로를 기존 구현으로 되돌릴 수 있음
- [ ] 세션 데이터 손실 없이 전환 가능
- [ ] 롤백 리허설 1회 수행

## 다음 단계 이동 조건
- [ ] 계약 테스트 100% 통과
- [ ] 스테이징 실사용 검증 통과
- [ ] 롤백 경로 확인 완료
- [ ] 단계 승인자 확인 완료
- [ ] 운영 전환 일정 확정
