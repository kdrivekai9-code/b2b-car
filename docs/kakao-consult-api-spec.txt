용어집

상담 세션 (Session)
●​ 상담원이 고객에게 메시지를 전송하기 위한 필수 조건입니다.
●​ 상담 세션이 생성된 상태에서 상담원은 메시지를 발송할 수 있습니다.
●​ 생성된 세션은 카카오톡 사용자의 마지막 메시지 수신 시점으로부터 30일간
  유지되며, 고객 메시지가 수신될 때 마다 연장됩니다.
    ○​ 세션 종료 시각은 사용자의 마지막 메시지 수신 시각을 기준으로, 다음
      정각으로부터 30일 후로 설정됩니다.
    ○​ 예) 8월 20일 15:15에 마지막 메시지를 수신했다면, 세션은 30일 뒤인 9월
      19일 16:00에 종료
●​ 상담 세션 생성 조건은 아래와 같습니다.
    ○​ 카카오톡 사용자가 상담 연결하기를 이용하여 상담을 요청
    ○​ 카카오톡에서 직접 채널 채팅방에 메시지를 전송하여 상담 요청
●​ 상담 세션 종료 조건은 아래와 같습니다.
    ○​ 상담원이 상담 종료
    ○​ 상담원이 카카오톡 사용자를 차단
    ○​ 카카오톡 사용자가 카카오톡 채널 채팅방에 "!종료"메시지 입력
    ○​ 카카오톡 사용자가 카카오톡 채널 채팅방 나가기
    ○​ 카카오톡 사용자가 카카오톡 채널을 차단
    ○​ 카카오톡 사용자의 마지막 메시지 수신 후 30일이 경과


사용자 키 (UserKey)
●​ 특정 카카오톡 사용자를 구분하기 위한 key로, 상담톡 메시지 수신시에 함께
  전달됩니다.
●​ 사용자 키는 카카오톡 채널 별로 유효합니다. 카카오톡 채널이 다르면, 사용자가
  동일하더라도 다른 사용자 키를 사용합니다.
●​ 사용자 키는 대소문자를 구분합니다.
●​ 카카오톡 사용자가 카카오톡 채널을 차단 후 해지시했을 경우에는 사용자 키가
  변경되지 않습니다.
●​ 카카오톡 탈퇴 후 재가입시에는 다른 사용자 키로 변경됩니다.


상담원
●​ 상담원은 카카오에서 제공하는 상담톡 API를 이용하는 주체를 의미하며 반드시
  사람을 지칭하는 것은 아닙니다.
●​ 상담을 요청한 카카오톡 사용자에게 상담원이 배정 되었는지 여부는 카카오에서는
  알 수 없습니다.
●​ 상담 진행시 직접적인 상담이 아닌 항목 선택 등의 메시지 발신도 카카오에서는
  상담원이 발송한 것(과금)으로 구분됩니다.
●​ 시스템 메시지 발신은 과금에서 제외 됩니다.


상담 메시지
●​ 상담원이 카카오톡 사용자에게 보낸 대화 메시지, 카카오톡 사용자가 상담원한테
  보낸 메시지 모두 상담 메시지로 합니다.
●​ 상담 메시지는 상담톡 시스템에는 저장되지 않으며 카카오톡 메시지 시스템에
  3일간만 저장됩니다.


챗봇 대화 내역 전달
●​ 챗봇 대화 내역 조회 혹은 사용자 메타 정보 수신 중 하나의 방법을 통해서 챗봇
  대화내역을 전달 받을 수 있습니다
●​ 상담시작이 된 상태에서 조회 시점 기준 이전 3일전 메시지까지 전달 받을 수
  있습니다.
●​ 챗봇 대화내역의 세부 스펙은 챗봇 고객센터로 문의 부탁드립니다.
상담 연결하기
상담톡은 상담톡API를 통한 상담 연결 외에도 웹사이트나 모바일 application 내의 특정 버튼을 통해

카카오톡 상담원 연결이 가능합니다. 이 방식은                                                 ,                           등의 버튼 클릭을 통해
이루어집니다.

❖​ PC에서 상담 연결 버튼 버튼을 통해 메타정보 전달 시 요청 페이지는 새창 또는 팝업 형태 요청하여야
   합니다.
❖​ 팝업의 최소 권장 사이즈는 w: 1024 h: 800입니다.
❖​ 봇과 상담톡을 동시에 이용하는 프로필일 경우, 봇(bot) 파라미터를 이용해 봇으로 상담을 연결할 수
   있습니다.
❖​ 상담 연결 버튼 클릭시 파트너사 페이지를 거쳐 카카오 로그인 페이지로 이동하는 경우에는 아래
